# 환생게임 · 사건 다양성 테스트판

**실제 PC·모바일 UI 검수 미완료.** [이 테스트판 열기](./) · [안정판으로](../../) · [배포 정보](release.json).

생일의 연간 처리와 연중 활동·후속을 나눈 독립 규칙 개발판입니다. 게임 규칙과 직접 작성한 합성 장면을 사용하며 실제 AI·외부 계정·결제·기기 간 동기화는 없습니다. 전체 게임 완성이나 사용자 플레이 검수 완료를 의미하지 않습니다.

이번 테스트판은 재학생·영아·휴학 문맥, 취미 조사와 사건 반복 선택을 개선합니다. 게임의 금액·판정·교육·훈련·관계 규칙은 유지합니다.

이번 03 테스트판은 전용 저장 키 lifemap.baseline.v1.test-20261016-scene-variety-03를 사용합니다. 이전 01·02 테스트판과 안정판의 기록을 자동으로 읽거나 복사·삭제·이관하지 않습니다. 처음에는 빈 서재로 열립니다. 이전 기록을 계속하려면 이전 테스트판에서 내보낸 JSON 파일을 여기에서 직접 가져오세요. 원래 테스트판의 기록은 그대로 남으며 가져온 복사본은 별도로 진행됩니다. 기존 v10 기록도 읽을 수 있습니다. 새 장면의 후속이 포함된 파일을 구판에 직접 가져오면 그 후속은 생략될 수 있습니다.

## 저장 호환

저장 v1–v10을 읽습니다. 기존 v9를 열람만 할 때는 내용을 다시 쓰지 않으며, 연중 진행을 실행해 저장하면 v10이 됩니다. v10은 이전 v9 테스트 실행물에서 실행할 수 없습니다. 구버전은 지원하지 않는 주 저장 또는 백업이 있으면 읽기 전용으로 멈추고 원본을 보존합니다. 자동으로 v9로 되돌리거나 저장 키를 이관하지 않습니다.

안정판의 저장 키는 별도이며 자동으로 읽거나 합치지 않습니다. 안정판 링크로 돌아가면 안정판의 원래 저장을 사용합니다. JSON 내보내기/가져오기는 사용자가 선택한 파일에만 적용합니다. 저장 파일을 GitHub에 올리지 마세요.

## 전환 전에 v9 파일 보관하기

1. 이전 테스트판에서 시간이 흐르고 있다면 먼저 멈추고 다른 게임 탭을 닫습니다. 삶 화면의 **⋯ 더 보기 → 전생의 집 · 기록 관리**(시작 화면에서는 **기록 관리**)로 생애 서재를 엽니다.
2. **휴지통을 포함한 전체 백업**을 누릅니다. 다운로드 목록에서 life-map-save-날짜-r번호.json 파일이 실제로 저장됐는지 확인하고, 전환 전 v9 파일임을 알 수 있는 이름으로 브라우저 밖에 따로 보관합니다. 앱의 알림은 다운로드 요청만 뜻하므로 취소·차단된 다운로드는 백업 완료가 아닙니다.
3. 현재 삶·완료 기록·보관한 삶·휴지통을 포함한 현재 메모리의 전체 JSON입니다. 정상적으로 읽은 v9 기록은 v9로 내보내며, 저장의 버전은 파일 맨 위 version에서 확인할 수 있습니다. 내보내기는 원래 JSON의 공백 같은 바이트 모양이나 주 저장/자동 백업 두 원본을 그대로 복사하는 기능은 아닙니다.
4. 파일 보관을 확인한 뒤 이전 탭을 닫고 새 테스트판을 진행합니다. 연중 진행 뒤의 v10 파일은 v9 파일을 덮어쓰지 않는 다른 이름으로 보관합니다.

자동 .backup은 다음 성공한 저장에서 직전 세대로 바뀝니다. 첫 v10 저장 직후의 v9 백업도 그다음 저장에서 v10으로 바뀔 수 있어 영구적인 v9 복귀를 보장하지 않습니다.

읽기 전용 오류 또는 이전 세대 복구 경고가 보이면 내보낸 파일을 최신 원본의 백업으로 간주하지 마세요. 특히 v10을 읽지 못한 구버전의 ‘현재 메모리 내용 내보내기’는 비어 있거나 이전에 읽은 내용일 수 있습니다. 저장을 지우거나 구버전으로 덮어쓰지 말고 v10 지원판에서 정상적으로 읽힌 기록을 별도로 내보내세요.

## 되돌리기

웹 코드의 철회가 브라우저의 v10 저장을 v9로 바꾸지는 않습니다. 새 진행 이후에는 v10을 먼저 내보내 보관하고 v10 지원 실행물에서 계속해야 합니다. 이전 v9 파일은 최신 v10 저장을 건드리지 않는 비어 있는 별도 브라우저 프로필의 이전 테스트판에서 ‘가져오기’로 불러올 수 있습니다. 가져오기는 기록 병합이며 같은 삶의 다른 시점은 거절되고 대상 환경설정은 유지됩니다. v9 파일에는 내보낸 뒤의 진행이 포함되지 않습니다. 원본 v10을 덮어쓰거나 삭제하는 자동 복구는 하지 않습니다.

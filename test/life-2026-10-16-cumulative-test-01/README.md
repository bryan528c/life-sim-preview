# 최신 테스트판

**실제 PC·모바일 UI 검수 미완료.** [테스트판 열기](./) · [안정판으로](../../) · [배포 정보](release.json).

기존 안정판 파일과 저장을 보존한 별도 누적 테스트판입니다. 새 인생, 보관 기록, 백업과 복구는 이 테스트판의 독립 브라우저 저장에만 접근합니다. 안정판 기록은 자동으로 읽거나 변환하지 않으며, 사용자가 내보낸 JSON 파일/텍스트를 직접 가져온 경우에만 복원합니다. 기기 간 자동 동기화와 실제 AI 연결은 없습니다.

최신판은 저장 v1–v9를 읽지만 최신 v9 저장을 안정판 v5로 가져올 수 있다는 의미는 아닙니다. 안정판으로 돌아가면 안정판의 원래 저장을 계속 사용합니다. 테스트판 기록은 별도로 내보내 보관하세요.

이 경로의 공개 파일은 검토된 실행 코드·허용된 공개 자료와 글꼴·배포 메타데이터뿐입니다. [타사 자료와 라이선스](THIRD_PARTY_NOTICES.md). 원고·관찰 자료·사용자 저장·비밀·로컬 서버는 포함하지 않습니다. 전체 게임 완성이나 실제 UI 검수 완료를 뜻하지 않습니다.
